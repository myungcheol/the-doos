## 프로젝트 전제

- **재스캔 없음**: 현재 스캔 파일을 그대로 사용한다. 없는 면은 `missing`으로 표시하고, 사이트에 “미수록”으로 안내한다.
- **AI**: 유료 API를 전제로 하지 않는다. 무료로 사용 가능한 이미지 처리 API 또는 로컬 OCR을 우선 검토한다.
- **검수**: 프로젝트 오너 1명이 수행한다. 전수 검수 부담을 줄이기 위해 신뢰도 기반 큐와 일괄 승인/표본 검수를 설계한다.
- **공개**: 전체 공개를 전제로 한다. 다만 생존자·주소·묘소 좌표 등 민감 정보의 masking 여부는 별도로 확인한다.
- **`上###`/`下###`**: `上159` = 본편 159면에 **부모(조상) 기록**이 있다, `下4` = 본편 4면에 **자손 기록**이 이어진다는 뜻. `T###`·`F###`는 `下###`의 오독이다.
- **단(段)**: 페이지를 가로로 나눈 줄. 같은 단 = 같은 세대, 바로 아래 단 = 다음 세대.

## 현재 상태

- 판독 규칙과 데이터 모델 문서화를 마치고, 실제 파이프라인을 만들기 시작한 단계입니다.
- **인벤토리 완료**: `data/manifests/pages.csv` 1,031행(전편 93 + 본편 938). 미수록 32행은 `page_type=missing`으로 기록했습니다.
- **파이프라인 초안 완료**: manifest 생성, 정규화 symlink, 프롬프트 생성, AI 호출, JSON 검증, OCR sidecar, 배치 실행.
- **검수 도구 초안 완료**: `python3 admin/server.py`로 이미지와 JSON을 나란히 보며 상태를 저장할 수 있습니다.
- **폴더 확정**: `scan/frontmatter/`(전편) / `scan/genealogy/`(본편). 표지는 `scan/` 루트.
- **파일명 확정**: 원본 3자리 zero-pad(`025.jpg`), 앱 경로 4자리(`0025.jpg`).
- **전편 63면 항렬표**는 `scan/frontmatter/063.jpg`로 확인했습니다. **전편 65~66면 조견색인**도 확보했습니다.
- 현재 없는 면: **전편 48·64·67~93면**, **본편 53·934·935면**. 재스캔·추적 없이 “미수록”으로 처리합니다.
- `.jpeg` 파일은 모두 `.jpg`로 정리했습니다.
- 남은 일: 20~30면 파일럿 파싱 → 검수 도구로 확인 → DB 적재 스크립트 작성.
