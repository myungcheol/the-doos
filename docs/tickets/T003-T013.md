# T003~T013 상세

상태와 선행 관계는 [티켓 원장](../tickets.md)을 따른다. 아래는 계획이며 구현 완료를 뜻하지 않는다.

<a id="t003"></a>

## T003 — 본문의 예외 표본 조사

- 설명: 판독 규칙이 달라지는 실제 사례를 확보한다.
- 범위: `scan/genealogy`에서 딸/사위·복수 배우자·妾·입양·쪽 연결·표제·세대 표기 없는 쪽을 조사한다. OCR 실행은 제외한다.
- 산출물: 사례별 파일 번호·영역·판독 근거·선정 이유를 담은 조사 문서.
- 완료 조건: 찾은 사례에 근거 위치와 적용 규칙이 있고 못 찾은 것은 미발견으로 남긴다.
- 검증: 원본과 위치를 대조하며 800~802를 판식 회귀 표본으로 포함한다.

<a id="t004"></a>

## T004 — 수동 정답 표본과 평가 기준

- 설명: OCR 문자·인물 분리·관계 오류를 따로 측정할 기준을 만든다.
- 범위: 소수의 연결된 페이지에 원문·이름 영역·정보 귀속·부모 관계를 수동 표시한다. 전체 책 전사는 제외한다.
- 산출물: 정답 fixture, 표본 설명, 평가 지표 정의.
- 완료 조건: 확실한 정답과 불확실성을 구분하고 페이지 간 관계 및 부분 날짜 사례가 있다.
- 검증: 영역이 원본 크기 안에 있는지, 관계가 근거 페이지에 맞는지 대조한다. 불확실한 값은 정답 분모에서 구분한다.

<a id="t005"></a>

## T005 — 단일 이미지 PaddleOCR 실행

- 설명: 규칙 처리 전 원문·좌표를 재현 가능하게 얻는다.
- 범위: Python 의존성 고정과 한 이미지 OCR CLI. LLM/VLM, DB, 인물 해석은 제외한다.
- 산출물: 환경 설정, CLI, OCR 결과 형식, 실행 안내.
- 완료 조건: 원문·좌표·점수·모델/라이브러리 버전과 실행 조건을 남긴다.
- 검증: 고정 표본에서 실제 실행하고 세로 한자 인식 결과를 보고한다. CPU 실행 가능 여부와 소요 시간도 기록한다.

<a id="t006"></a>

## T006 — 페이지와 세로 열 전처리

- 설명: 표제와 인접 페이지 글이 인물 본문으로 들어가는 오류를 줄인다.
- 범위: 테두리·단·열 검출, 필요한 회전/크롭과 원본 좌표 복원. 인물 의미 해석은 제외한다.
- 산출물: 전처리 모듈, 좌표 변환 정보, 전후 비교 산출물.
- 완료 조건: 세대·책 제목·옆 페이지가 없어도 실패하지 않고 빈 단을 유지한다.
- 검증: 001~003과 800~802에서 영역·좌표 왕복을 비교한다. 검출 실패는 명시적으로 남긴다.

<a id="t007"></a>

## T007 — 인물 이름과 본문 영역 분리

- 설명: 한 사람의 이름·설명이 다른 사람과 섞이지 않게 한다.
- 범위: 큰 이름·子/女/女·열 위치 기반 출현 분리. 동명이인 병합·계보 확정은 제외한다.
- 산출물: 영역 파서, 출현 데이터, 표본 결과.
- 완료 조건: 이름과 설명 영역·원문 표지를 보존하고 女 항목은 미검수로 식별한다.
- 검증: 조밀한 쪽·빈 단·설명 이어짐에서 정답 영역과 비교한다. 본문 속 子를 이름으로 잘못 분리하는 사례를 검사한다.

<a id="t008"></a>

## T008 — 생몰과 일반 부가 정보 파서

- 설명: 인물 설명을 검색·풀이 가능한 항목으로 나눈다.
- 범위: 출생·사망·관직·학력·묘소와 미분류 원문. 날짜 서기 환산·배우자 해석은 별도 티켓이다.
- 산출물: 규칙 파서, 정보 항목 형식, 입력/기대 결과 fixture.
- 완료 조건: 항목의 소유 인물·원문 범위·날짜 원래 정밀도를 보존한다.
- 검증: 생몰과 이장일 혼동, 연만/연월만, 미해석 구간 보존을 검사한다.

<a id="t009"></a>

## T009 — 복수 배우자 설명 파서

- 설명: A의 설명 속 배우자를 독립 인물·혼인으로 저장할 입력을 만든다.
- 범위: 配 구간·복수 배우자·해당 구간의 妾·생몰 귀속. 실제 DB 저장은 제외한다.
- 산출물: 배우자 추출 구조, 원문 참조, 규칙과 fixture.
- 완료 조건: A의 부가 설명을 유지하며 B/C 인물 후보·A–B/A–C 관계 후보를 출력한다. 配는 배우자, 妾은 첩이다.
- 검증: 다른 구간의 妾 오적용, 배우자 친족을 자녀로 오인, 배우자 날짜를 A에 귀속하는 오류를 검사한다.

<a id="t010"></a>

## T010 — 같은 쪽 부모·자녀 추출

- 설명: 사용자가 설명한 배치를 계보 연결 규칙으로 구현한다.
- 범위: 윗단 같은 열, 빈 열이면 윗단 오른쪽 첫 부모 찾기. 다른 쪽 조회는 제외한다.
- 산출물: 배치 규칙 모듈, 관계 후보와 근거, fixture.
- 완료 조건: 왼쪽 B D C 배치에서 오른쪽 C·D(아들), B(딸)를 같은 A에 연결한다. 女 미검수는 관계도 검수 대상으로 둔다.
- 검증: 외동, 여러 아들/딸, 서로 다른 부모 그룹, OCR 이름 미검출, 여성 부모 예제를 검사한다.

<a id="t011"></a>

## T011 — 다른 쪽의 인물·부모 연결

- 설명: 페이지를 넘는 인물 설명과 부모 탐색을 이어준다.
- 범위: 上/下 참조·같은 계보의 윗단 오른쪽 탐색·여러 출현 연결. 전체 동명이인 자동 병합은 제외한다.
- 산출물: 참조 해석기, 해결/미처리/스캔 누락 상태.
- 완료 조건: 001→002/003의 재출현과 페이지 경계의 부모를 구분해 연결한다. 근거 없는 연결은 보류한다.
- 검증: 상대 쪽 선처리/후처리, 스캔 누락, 같은 이름의 다른 인물, 경계 밖 계보 연결 방지를 검증한다.

<a id="t012"></a>

## T012 — 독음 후보 사전과 조회

- 설명: LLM 없이 한자 이름의 한글 독음 후보를 제공한다.
- 범위: 사전 출처·버전·이용 조건, 글자 독음과 인명 예외 조회. 확정 독음 자동 결정은 제외한다.
- 산출물: 고정 사전 또는 재현 가능한 취득 도구, 후보 함수, 출처 문서.
- 완료 조건: 복수 독음과 미등록 한자를 처리하고 후보·확정 값을 분리한다.
- 검증: 복수 독음·성씨 예외·미등록 글자·호환 한자를 검사하고 원문이 변하지 않는지 확인한다.

<a id="t013"></a>

## T013 — 정형 항목 한국어 풀이

- 설명: 판독한 사실을 한국어로 이해할 수 있게 표시한다.
- 범위: 생몰·배우자 등 정형 항목 문장 틀. 자유 한문 전체 번역은 제외한다.
- 산출물: 풀이 함수, 항목별 템플릿, fixture.
- 완료 조건: 미해석 원문과 자동/수동 풀이를 구분하고 보충 월일을 실제 생일로 표현하지 않는다.
- 검증: 연만/연월만 날짜, 첩, 미상 정보, 수동 풀이 보존과 반복 실행 결과를 검사한다.
