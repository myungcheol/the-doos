# T026~T034 상세

상태와 선행 관계는 [티켓 원장](../tickets.md)을 따른다. 아래는 계획이며 구현 완료를 뜻하지 않는다.

<a id="t026"></a>

## T026 — 일반 책 열람

- 설명: 누구나 스캔을 책 순서로 읽게 한다.
- 범위: 페이지 이동·번호 이동·확대·누락 표시. 인물 상세와 검색은 제외한다.
- 산출물: 공개 열람 화면과 스캔 제공 경로.
- 완료 조건: 앞부분과 본문 순서를 구분하고 누락 페이지를 없는 파일 오류로 방치하지 않는다.
- 검증: 001/마지막 쪽 이동, 053·934·935 누락, 작은 화면·확대 상태의 이동을 확인한다.

<a id="t027"></a>

## T027 — 인물 선택과 상세

- 설명: 스캔에서 선택한 사람의 정보를 공개한다.
- 범위: 영역 클릭·인물 상세·다른 출현 이동·배우자 정보. 트리 확장은 제외한다.
- 산출물: 공개 인물 상세 화면과 조회 API.
- 완료 조건: 한자·후보/확정 독음·풀이·미검수·날짜 보충 여부와 원문 근거를 표시한다.
- 검증: 겹친 영역·여러 출현·복수 배우자·미상 이름·연도만 있는 날짜를 확인한다.

<a id="t028"></a>

## T028 — 선조와 후손 트리 확장

- 설명: 선택 인물 중심으로 필요한 세대만 펼친다.
- 범위: 선조 위쪽·후손 아래쪽의 한 단계 반복 확장. 전체 가계 일괄 시각화는 제외한다.
- 산출물: 트리 화면과 조회 연동.
- 완료 조건: 부모/자녀 노드 선택으로 다음 단계를 펼치고 상세·스캔으로 이동한다.
- 검증: 선조·후손 각각 3단계, 형제 가지, 여성 부모, 미연결/누락 근거, 반복 클릭 중복 노드를 확인한다.

<a id="t029"></a>

## T029 — 이름 검색과 스캔 이동

- 설명: 책 페이지를 모르는 사용자도 인물을 찾게 한다.
- 범위: 한자·확정/후보 독음 검색, 결과 구분, 스캔 영역 이동. 본문 전체 검색은 제외한다.
- 산출물: 검색 조회와 화면, 인덱스.
- 완료 조건: 동명이인을 별도 결과로 보여주고 해당 출현 위치로 이동한다.
- 검증: 한자·독음 후보·동명이인·결과 없음·여러 출현·긴 결과 목록을 확인한다.

<a id="t030"></a>

## T030 — 대표 표본 전체 흐름 평가

- 설명: 구현 기능이 실제 족보에서 연결되는지 확인한다.
- 범위: 표본의 OCR→DB→수정→공개→검색/트리 평가. 전체 배치 실행과 결함 수정 자체는 제외한다.
- 산출물: 평가 보고서, 오류 목록과 후속 결함 티켓.
- 완료 조건: 문자·인물·관계 평가를 분리하고 전체 확대 조건과 미해결 결함을 명시한다.
- 검증: 수정 후 재처리 보존, 배우자 인물/혼인, 女 검수, 부분 날짜, 페이지 누락을 포함해 재현한다.

<a id="t031"></a>

## T031 — 전체 본문 처리와 품질 보고

- 설명: 검증된 파이프라인을 모든 본문에 적용한다.
- 범위: genealogy 전체 배치·실패/미연결/미검수 집계. 전체 수동 검수 완료는 제외한다.
- 산출물: 실행 기록, 품질 보고서, 재시도 목록.
- 완료 조건: 기존 검수 결과를 유지하면서 모든 존재하는 본문 파일의 처리 상태를 보고한다.
- 검증: 입력 파일/성공/실패 수를 맞추고 일부 재시도와 재처리 보존을 확인한다.

<a id="t032"></a>

## T032 — 무료 호스팅 조사와 선택

- 설명: 실제 데이터 크기와 운영 방식에 맞는 서비스를 고른다.
- 범위: 웹·Postgres·이미지 저장·인증·요금/제약 조사. 배포 변경은 제외한다.
- 산출물: 날짜·근거 링크가 있는 비교표, 선택 결정.
- 완료 조건: 무료 한도와 중단/유지 조건, 로컬 OCR 결과 반영 방법, 예상 사용량을 비교한다.
- 검증: 당시 공식 문서와 실제 산출물 용량을 대조한다. 조건을 충족하는 무료 서비스가 없으면 한계를 기록한다.

<a id="t033"></a>

## T033 — 백업·전송·복원

- 설명: 로컬 결과를 서버로 옮기고 복구할 수 있게 한다.
- 범위: DB와 스캔/파생 이미지의 백업·전송·복원 절차. 운영 서비스 전환은 제외한다.
- 산출물: 명령/스크립트, 복원 안내, 검증 기록.
- 완료 조건: 임시 환경에서 인물·관계·수정 이력·이미지 연결까지 복원한다.
- 검증: 레코드 수·샘플 관계·파일 해시를 대조하고 기존 DB를 덮지 않는 절차를 검증한다.

<a id="t034"></a>

## T034 — 공개 배포와 운영 안내

- 설명: 선택한 서비스에서 공개 열람과 관리자 검수를 제공한다.
- 범위: 배포 설정·공개 연결·운영 점검. 새 제품 기능은 제외한다.
- 산출물: 배포 설정, 서비스 주소, 운영/복구 문서.
- 완료 조건: 공개 읽기·관리자 쓰기·스캔·검색·트리·백업이 배포 환경에서 동작한다.
- 검증: 외부에서 주요 흐름과 권한을 점검하고 재배포 후 자료 유지 및 복구 절차를 확인한다.
