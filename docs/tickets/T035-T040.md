# T035~T040 상세

상태와 선행 관계는 [티켓 원장](../tickets.md)을 따른다. 아래는 계획이며 구현 완료를 뜻하지 않는다.

<a id="t035"></a>

## T035 — 고려 왕대와 자체 연호 대응표

- 설명: 고려 인물의 왕대·연호 날짜를 서기 연도로 찾을 근거를 만든다.
- 범위: 고려 왕대·자체 연호·즉위/원년·복위 구간·별칭 수집. 변환 코드와 중국 연호는 제외한다.
- 산출물: 왕/연호/서기 대응 데이터, 행별 출처, 범위·미확인 목록.
- 완료 조건: 각 왕대 구간의 기년과 서기 대응, 유효 범위 및 확인 상태가 있다.
- 검증: 국사편찬위원회 사료와 원년/끝년/복위 경계를 대조한다. 충혜왕 후2년=1341과 공민왕5년=1356을 포함한다.

<a id="t036"></a>

## T036 — 중국 연호 대응표

- 설명: 고려 및 조선 기록에서 중국 연호로 적힌 날짜를 해석한다.
- 범위: 고려와 관련된 중국 왕조 연호, 조선 기록의 명·청 연호 및 반복 연호 구분. 국내 왕대 표는 제외한다.
- 산출물: 왕조·황제·연호·서기 대응 데이터와 근거/수록 범위 문서.
- 완료 조건: 연호의 발행국·황제·사용 구간을 구분하고 한국에서 채택한 시기와 연호 자체의 기간을 혼동하지 않는다.
- 검증: 건덕 원년=963, 지정16년=1356, 홍치8년=1495 및 동명/복수 구간을 대조한다. 표가 커지면 왕조별 하위 티켓으로 분할한다.

<a id="t037"></a>

## T037 — 조선 왕대와 연호 대응표

- 설명: 조선부터 대한제국까지 왕대·연호를 서기로 연결한다.
- 범위: 조선 왕대의 즉위년/원년·별칭, 건양·광무·융희. 음양력 일 단위 변환은 제외한다.
- 산출물: 왕대/연호 대응 데이터, 행별 출처, 경계 검증 노트.
- 완료 조건: 왕 이름 기반 기년과 연호 기반 기년이 구분되고 교체 연도 범위를 보존한다.
- 검증: 실록의 연산 즉위년=1494/원년=1495 등과 각 왕대 경계를 대조한다.

## T038 — 서기 연도 환산과 부분 날짜 정규화

- 설명: 조사한 대응표를 생몰 정보 처리에 사용한다.
- 범위: 왕대/연호 조회·간지 교차 검사·월일 기본값·flag. 역사적 음양력 일 단위 변환 엔진은 제외한다.
- 산출물: 순수 변환 함수, 정규화 형식, 테스트와 근거 버전 기록.
- 완료 조건: 월 없음은1·일 없음은1로 보충하며 원문 정밀도·역법·두 flag를 보존한다. 모호한 연도는 후보로 반환한다.
- 검증: 연만/연월만/완전 날짜/실제1월1일, 즉위년·복위, 범위 밖, 연호-간지 충돌, 음력2월30일을 검사한다.

## T039 — 배우자 인물과 혼인 스키마

- 설명: A의 배우자 설명과 독립된 B/C 인물·혼인을 함께 저장한다.
- 범위: 혼인 관계·배우자 지위·근거와 A의 부가 정보 참조. 부모 관계 추론·편집 화면은 제외한다.
- 산출물: 혼인 마이그레이션, 데이터 사전, 저장 fixture.
- 완료 조건: A–B/A–C를 저장하고 B/C의 생몰은 각 인물에 귀속한다. 설명 원문에서 혼인과 배우자로 이동할 수 있다.
- 검증: 복수 배우자·첩/미상·이름 미상 배우자·중복 관계 재적재·배우자 수정 후 A의 설명 참조 유지를 확인한다.

## T040 — 女 항목의 딸·사위 검수

- 설명: 인물 표기의 의미를 사람이 판정하고 가족관계를 바로잡는다.
- 범위: 미검수/딸/배우자(사위) flag와 판정에 따른 인물·혼인 선택 UI. 자동 성별 추정은 제외한다.
- 산출물: 검수 폼/API, 판정 이력, 전환 fixture.
- 완료 조건: 딸이면 딸 인물에 연결하고 사위면 별도 인물과 딸–사위 혼인을 설정한다. 이름 미상 딸을 지원한다.
- 검증: 미검수→딸/사위, 판정 번복, 기존 인물 재사용, 사위를 친자녀로 연결한 오류 정정과 관계 이력을 확인한다.
