# T013 정형 항목 한국어 풀이

## 입력과 결과

`scripts/korean_explanations.py`는 T008의 분류 항목에 한국어 문장 후보를 붙인다. 각 항목의 `explanation.automatic`은 규칙으로 만든 문장이고 `explanation.manual`은 검수자가 나중에 입력한 문장이다. 두 필드는 독립적이며 재실행해도 수동 풀이를 덮어쓰지 않는다. `raw`, `source_refs`, 배우자 소속 정보는 변경하지 않는다.

| 종류 | 입력 예 | 자동 풀이 후보 |
|---|---|---|
| 출생·사망 | `甲辰生`, `甲辰二月卒` | `甲辰 (월·일 미상) 태어남.`, `甲辰 2월 (일 미상) 사망함.` |
| 배우자·첩 | `配金氏`, `妾李氏` | `배우자 金氏로 기록됨.`, `첩 李氏로 기록됨.` |
| 관직·학력 | `郡守`, `進士` | `관직 기록: 郡守.`, `과거·학력 기록: 進士.` |
| 미분류·일반 서술 | `不詳`, `字某號某有孝行` | 자동 풀이 없음; 원문을 검수 화면에 유지 |

배우자·첩의 생몰은 그 배우자 범위 내부에 풀이를 붙인다. 성명이 판독되지 않거나 날짜 글자가 이름으로 잘못 잡힌 경우 `이름 미상`이라고 표시하고 추정한 이름을 문장에 넣지 않는다.

월·일을 읽지 못한 날짜에는 `미상`을 표시한다. T038에서 정렬·저장 목적으로 월·일을 `1`로 보충하더라도 풀이에는 원문에서 판독한 구성요소만 사용한다. 간지 연도를 특정 서기 연도로 환산하지 않는다. 날짜 구성요소가 범위를 벗어났다는 경고가 있으면 자동 풀이를 보류한다. 숫자 네 자리 연도는 원문과 함께 표시하며 역법은 추정하지 않는다.

검수 화면의 생몰·배우자/혼인·일반정보 탭에서 `자동 풀이 후보` 또는 `한국어 풀이 없음 · 원문 확인 필요`를 확인한다. 아직 수동 입력·DB 저장 기능은 없다. 풀이 함수는 기존에 들어온 `manual`을 보존하도록 설계되어 있다.

## 검증

`tests/fixtures/explanation-samples.json`은 실제 인물 등록 데이터가 아니라 규칙 확인 예시다. 연만·연월만·연월일, 첩, 이름 미상 배우자, 미분류 원문, 관직·학력 사례를 포함한다.

```bash
.venv/bin/python -m unittest tests/test_korean_explanations.py -v
```
