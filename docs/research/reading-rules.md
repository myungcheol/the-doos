# 세로쓰기 족보 판독 규칙 — 초기 조사

조사일: 2026-11-18. 관련 티켓: T001. **전체 책에 적용 검증된 규칙은 아니다.**

## 근거와 확신 구분

- `일반`: 외부 독법 안내. 이 책의 실제 표기와 대조해야 한다.
- `관찰`: 실제 스캔에서 확인한 배치·문자. 다른 페이지에 자동 일반화하지 않는다.
- `가설`: 구현 후보이며 표본 검증 전 확정 관계를 만들지 않는다.
- `정책`: 사용자 합의 또는 손실 없는 처리를 위한 구현 방침.
- `사용자 설명`: 이 책의 판독 규칙에 대한 사용자 제공 정보. 구현 기준으로 채택하되 전체 표본 검증과는 구분한다.

## 관계와 페이지 연결

| ID | 규칙 / 근거 | 구현 시 처리와 예외 |
|---|---|---|
| R12 | 사용자 설명: 자녀는 오른쪽→왼쪽으로 아들 나이순, 이어 딸 나이순이다. 한 자녀면 바로 윗단 같은 열의 A에 연결한다. | 여러 자녀의 윗단 같은 열이 비면 윗단 오른쪽의 첫 인물 A에 연결한다. 예: B(첫째 딸), C(둘째 아들), D(셋째 아들)는 왼쪽부터 B D C이며 셋 모두 A의 자녀다. 같은 쪽에 A가 없으면 연결된 쪽의 같은 세대 단을 이어서 찾는다. 스캔 누락·계보 경계·OCR 미검출 때문에 비었을 가능성은 구분하고 근거가 없으면 미연결로 둔다. |

| R14 | 관찰 P2 상단: 이전 쪽에서 이어지는 설명이 페이지 오른쪽부터 놓여 있다. | 같은 쪽의 인물 이름 옆에 있는 텍스트만 수집하면 설명을 잃을 수 있다. 설명의 여러 영역과 쪽을 연결할 수 있어야 한다. |
| R15 | 정책 D005: 책의 부모·자녀 연결을 따른다. | A의 배우자 B를 A의 자녀 C의 부모로 자동 추가하지 않는다. D→E가 명시되면 D의 성별과 관계없이 보존한다. |
| R16 | 정책 D011 / 사용자 확인: 아직 읽지 않은 쪽과 스캔 자체가 없는 쪽이 모두 존재한다. | 미처리·스캔 누락을 구분해 참조 상태를 남긴다. 부모 없음이나 후손 없음으로 바꾸지 않는다. 누락을 건너뛰어 아무 인물에나 연결하지 않는다. 순환·자기 참조는 오류로 분리한다. |

## 후속 확인과 구현 순서

1. T002: 파일명과 실제 쪽수를 구분하고 사용자 확인에 따라 번호 공백을 스캔 누락으로 등록한다.
2. T003: `scan/genealogy`에서 딸/사위·복수 배우자·입양·쪽 연결·다른 판식의 표본을 확보한다. 없는 사례는 미발견으로 기록한다.
3. T004: 실제 영역 좌표와 원문·관계 정답을 소수 표본에 기록한다. 위 관찰은 아직 좌표 정답 데이터가 아니다.
4. T005~T011: 원문 인식, 열 정렬, 인물 분리, 정보 추출, 관계 추출을 나눠 구현·평가한다.

이번 조사는 일반 독법, 사용자 설명, 6개 페이지 관찰에 한정한다. 사용자 배치 규칙은 구현 기준으로 반영했으나 전체 OCR 정확도와 관계 추출 정확도를 검증한 것은 아니다. 연호 대응표의 전체 수집은 별도 티켓으로 진행한다.
