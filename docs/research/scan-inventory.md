# 스캔 목록과 누락 번호

조사일: 2026-11-18. 티켓: T002.

이 문서는 T002의 일회성 조사 결과를 남긴다. 번호가 붙은 JPEG를 실제로 세고, 번호 공백을 확인했다. 실행 프로그램이 읽는 데이터 파일은 아니다. OCR 입력 목록은 파이프라인을 만드는 티켓에서 실제 파일을 조회해 생성한다. 파일 번호와 책의 인쇄 쪽수는 별개이며, 인쇄 쪽수 전체 대조는 아직 하지 않았다.

| 구분 | 존재하는 파일 | 스캔이 없는 번호 | OCR 대상 |
|---|---:|---|---|
| frontmatter | 64 | 048, 064 | 아니오 |
| genealogy | 935 | 053, 934, 935 | 예 |

사용자가 확인한 대로 번호 공백은 해당 페이지의 스캔이 없는 것이다. 양끝 범위 밖의 번호는 자동으로 누락이라고 판단하지 않는다. `scan/앞표지.jpg`는 번호가 없는 표지이므로 이 표의 페이지 항목에 포함하지 않는다.

검증: 번호가 붙은 실제 파일 999개와 범위 안의 빈 번호 5개를 확인했다. 이 작업은 인쇄 쪽수를 이미지별로 판독하거나 누락 스캔을 복원하지 않는다.
