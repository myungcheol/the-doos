## 비교 방법

- 문자는 동일 영역에서 세로 읽기 순서로 비교한다. 확정된 전사만 문자 오류율 `(삽입 + 삭제 + 대체) / 정답 글자 수`에 넣는다. 전사되지 않은 영역을 누락 오류로 세지 않는다. Unicode 정규화와 이체자 처리 여부는 평가할 때 따로 기록한다.
- 이름 영역은 `geometry_status`가 `confirmed`인 영역에 한해 원본 좌표에서 겹침 비율(IoU)을 계산한다. 현재 좌표는 모두 `draft`이므로 수치 평가용 정답으로 쓰지 않는다.
- 정보 귀속은 `information_owner` 관계를 기준으로 맞춘 수와 놓친 수를 별도 집계한다. 005의 우측·상단 내용을 해당 인물에 잘못 귀속하면 오류다. 아직 설명 영역 전체 경계가 미확정이므로 해당 영역의 검출 점수는 내지 않는다.
- 부모·자녀와 페이지 간 동일 인물 연결은 방향과 종류를 포함해 각각 정답 관계와 비교한다. 정답에 없는 관계가 실제로 틀렸는지는 주석 범위 밖에서는 판단하지 않는다. 전체 페이지의 정밀도는 이 부분 표본만으로 계산하지 않는다.
- `user_confirmed`만 OCR·관계 점수에 사용한다. `uncertain`은 점수의 분모와 정답으로 사용하지 않는다. 좌표 상태와 내용 상태는 별도로 관리한다.

표본 보강 과제: 036쪽의 두 글자 딸 이름과 `xx人` 부기, 800~802쪽의 판식, 실제로 연도만 있는 날짜를 좌표와 함께 검수한다. 032쪽은 간지와 월이 있는 부분 날짜이며 서기 연도 변환의 정답이 아니다.
