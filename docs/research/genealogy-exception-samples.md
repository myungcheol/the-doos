# 본문의 예외 표본 조사

조사일: 2026-11-18. 티켓: T003. 범위는 `scan/genealogy`의 이미지 직접 열람이다. OCR은 실행하지 않았다.

## 조사 방법과 한계

- 연속 표본: 001~046쪽을 직접 확인했다.
- 분산 표본: 050, 099~101, 199~201, 299~301, 375, 400, 500, 600, 700, 800~802, 900쪽을 직접 확인했다.
- 아래의 “영역”은 페이지 안의 상대 위치다. 픽셀 좌표와 완전 전사는 T004에서 만든다.
- 확인하지 못한 표기는 이 책 전체에 없다는 뜻이 아니다. 찾지 못한 유형은 자동 판독 규칙으로 확정하지 않는다.

## 확보한 사례

| 유형 | 파일과 영역 | 관찰 | 적용할 규칙 |
|---|---|---|---|
| 인물 설명의 일반 배치 | [005](../../scan/genealogy/005.jpg) / 하단 중앙 `子廷薰` | 본문의 일반 규칙상 인물의 부가 정보는 그 이름 왼쪽에 온다. 따라서 `子廷薰` 왼쪽만 해당 인물 정보이며, 오른쪽·위쪽은 해당 인물 정보가 아니다. 이 인물의 배우자는 한 명이다. | 모든 인물에 이름 왼쪽 영역만 부가 정보로 귀속한다. 텍스트가 가깝거나 주변에 `配`가 여러 번 보여도 오른쪽·위쪽 내용을 같은 인물에게 연결하지 않는다. |
| 배우자 설명과 본인 설명의 경계 | [020](../../scan/genealogy/020.jpg) / 19~20세대 단, 우측 인물 설명 | 큰 이름 옆의 작은 세로 열에 `配`가 있고 배우자 본관·성씨로 보이는 설명이 이어진다. | `配`부터 다음 인물 경계까지를 배우자 후보 구간으로 잡되, 해당 구간의 날짜·묘소를 본인에게 자동 귀속하지 않는다. |
| `女` 뒤 세 글자 | [004](../../scan/genealogy/004.jpg) / 13세대 단 중앙 오른쪽 `女金世英` | `女` 다음의 세 글자 `金世英`은 두씨 딸의 이름이 아니라 그 딸의 신랑 이름이다. | `女` + 성 1글자 + 이름 2글자는 사위 인물 후보로 저장한다. 딸은 이름 미상 두씨 인물로 만들고, 검수 후 딸–사위 혼인 관계를 연결한다. |
| `女` 뒤 두 글자 | [008](../../scan/genealogy/008.jpg) / 14~16세대 단 | `女` 뒤 두 글자는 신랑 이름이 아니라 두씨집안 딸의 이름을 나타낸다. | `女` + 이름 2글자는 두씨 딸 인물 후보로 저장한다. 사위·혼인 관계는 자동 생성하지 않는다. |
| `xx人` 부기 | [036](../../scan/genealogy/036.jpg) / 18~19세대 단 | `女` 항목 옆에 작은 `…人` 부기가 반복된다. | `xx人`은 본관이 `xx`인 인물과 결혼했다는 뜻이다. 본관을 혼인 상대의 속성으로 보존하되, 이름은 만들지 않는다. `人`만 있으면 본관 미상으로 보고 무시한다. |
| 여성 항목의 혼합 배치 | [043](../../scan/genealogy/043.jpg) / 상단 16세대 단 | `女` 항목이 아들 `子` 항목과 같은 세대 단에 섞여 있고, 항목마다 글자 수와 부기가 다르다. | 여성 항목을 제외하거나 아들로 치환하지 않는다. `女` 뒤 글자 수, `xx人` 부기, 형제자매 위치를 각각 보존한다. |

| 책 제목·세대 표기의 선택성 | [800](../../scan/genealogy/800.jpg), [801](../../scan/genealogy/801.jpg), [802](../../scan/genealogy/802.jpg) | 800·802쪽에는 우측 세대 표기가 있고 제목은 보이지 않는다. 801쪽에는 좌측 제목이 있고 세대 표기는 보이지 않는다. 세 쪽 모두 옆 페이지는 보이지 않는다. | 제목·세대·인접 쪽은 선택 요소다. 없다고 실패하거나 본문을 다른 쪽과 합치지 않는다. |

## 미발견 또는 보류한 유형

| 유형 | 조사 결과 | 처리 |
|---|---|---|
| `妾` 표지 | 조사 범위에서 명확하게 읽히는 사례를 찾지 못했다. | `妾`이 인식되면 배우자 지위를 첩으로 설정하는 규칙은 유지한다. 실제 표본이 확보되기 전까지 다른 표기로 첩을 추정하지 않는다. |
| `繼子`·`系子` 또는 입양 대상·방향이 분명한 완전 사례 | 033쪽에서 `出系` 후보만 확보했다. | 입양 관계 방향과 대상 인물 연결은 T004 이후 별도 표본으로 검증한다. |
| 여성 항목의 딸/사위 확정 사례 | `女` 표지는 여러 쪽에서 확인했지만, 이 조사만으로 각 항목의 지위를 확정하지 않았다. | T040의 검수 화면에서 사람이 판정할 수 있게 한다. |

## T004에 넘길 표본

1. 001~003: `下N` 참조와 페이지를 넘는 인물 설명.
2. 005: 인물의 좌측 설명 영역과 우측·상단 인접 영역의 소속 분리.
3. 033: `出系` 후보.
4. 004·008·036: `女` 뒤 글자 수와 `xx人` 부기 분리.
5. 800~802: 제목·세대 표기가 각각 없는 판식 회귀 확인.

이 문서는 사례의 존재와 구현상 주의점을 기록한다. 인물 이름·관계·정확한 원문을 정답 데이터로 확정하지 않는다.
