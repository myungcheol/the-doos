## 기록

### 2026-11-09 — Qt 입력기 경로와 OCR 선택, 성별 검수

- **문제/원인:** OpenCV Linux wheel이 import 중 `QT_QPA_PLATFORM_PLUGIN_PATH`와 `QT_QPA_FONTDIR`을 자체 경로로 변경한다. 이 경로에는 Qt 입력기 플러그인이 없어 PySide6의 입력기 탐색을 방해할 수 있다. 확인 환경에는 IBus/Fcitx 실행 파일도 없었다. OCR 선택 시 popup 처리 중 이미지 장면을 다시 그리는 타이밍도 문제 후보였다.
- **수정:** OpenCV가 설정한 경로만 이전 사용자 설정으로 복원하고 OCR 선택에 따른 장면 갱신을 이벤트 루프 다음 차례로 미룬다. 원문 子/女 표식과 별도의 검수 성별을 저장하며 Streamlit 저장도 기존 성별 값을 보존한다.
- **검증/한계:** Qt offscreen의 popup 클릭과 합성 입력기 이벤트, 성별·원문·기존 데이터 보존 테스트를 실행한다. 실제 IBus/Fcitx 한글 조합 및 한자 변환은 입력기가 없는 환경이라 검증하지 못했다.
- **관련 커밋:** 이 기록을 포함한 커밋.

### 2026-11-09 — 데스크톱 검수 화면 및 CJK 글꼴 개선

- **문제:** 기본 Qt 화면은 검수 목록을 훑기 어렵고, 한글·한자 글꼴이 없는 환경에서 글자가 표시되지 않았다. `fc-list :lang=ko` 및 `:lang=zh`에서 사용 가능한 글꼴이 없었다.
- **선택:** 제공된 데모 소스 사진을 참고해 어두운 테마, 인물 검색·상태 목록과 고정 저장 버튼을 추가했다. Noto Sans CJK KR의 OFL 글꼴과 라이선스를 포함해 Qt 앱에서 직접 등록한다. 기존 검수 데이터 형식은 바꾸지 않는다.
- **검증:** Qt offscreen에서 한글·한자의 글리프 지원과 인물 검색·선택을 확인한다. 모든 희귀 한자 및 실제 데스크톱 환경의 입력기 동작을 보장하지는 않는다.
- **관련 커밋:** 이 기록을 포함한 커밋.

### 2026-11-09 — PySide6 데스크톱 검수 UI 추가

- **맥락:** 기존 Streamlit UI를 유지하면서 별도의 데스크톱 검수 창을 제공한다.
- **선택:** PySide6 화면에서 기존 검수 상태 및 내보내기 함수를 사용해 JSON 형식을 공유한다. 저장은 명시적이며, 파일 해시로 외부 검수 상태 변경을 감지한다. 이미지와 OCR 좌표는 원본 좌표를 사용하고 ROI 대체 이미지에는 오프셋을 적용한다.
- **절충:** 초기 화면은 인물 편집과 관계 승인·거절·수동 연결을 지원한다. 공용 레지스트리 갱신, 기존 UID 선택, 판본 메타데이터 편집, 관계 후보의 인물 교체와 되돌리기는 기존 Streamlit에서 수행한다. Streamlit 함수를 공유하므로 데스크톱 의존성에도 Streamlit이 필요하다.
- **검증:** 임시 합성 OCR 결과와 Qt offscreen 테스트로 첫 화면, 저장 호환성, 기존 데이터 보존, 외부 수정 충돌, 수동 관계 중복을 확인한다. 실제 디스플레이 상호작용과 OCR 모델 추론은 별도 검증이 필요하다.
- **관련 커밋:** 이 기록을 포함한 커밋.

### 2026-11-09 — 검수 UI OCR focus 첫 렌더링 오류 수정 (과거 작업 요약)

- **문제:** 인물을 선택하지 않은 첫 화면에서 `UnboundLocalError: cannot access local variable 'focus'`가 발생함.
- **원인:** `focus`가 `selected_for_overlay` 조건 안에서만 할당됐지만, 이미지 뷰어 payload에는 무조건 전달됨.
- **수정:** 조건문 이전에 기본 focus를 계산하고, 오래된 세션 선택값은 `all`로 대체하도록 처리함. 회귀 테스트 두 개 추가.
- **검증 범위:** GitHub 반영 및 회귀 테스트 코드 추가 확인. 실제 Streamlit 브라우저 테스트와 CI 통과 여부는 이 기록만으로 확인되지 않음.
- **관련 커밋:** [3b6323a](https://github.com/myungcheol/the-doos/commit/3b6323a6f9c3a1ada19ed74bf55b3e834efc8577)
- **재발 방지:** 인물 미선택·첫 페이지 로드 경로도 검수 UI 테스트 대상에 포함할 것.
