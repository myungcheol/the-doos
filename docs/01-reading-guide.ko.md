# 두릉 두씨 세보 읽는 법

> 대상: 『杜陵杜氏世譜』(1986년 간행, 金浦派) 스캔본  
> 목적: 문중 구성원과 검수자가 한 페이지를 읽고 인물·관계를 추적할 수 있게 하는 안내서  
> 상태: 초안. `[확인 필요]`로 표시한 항목은 문중 어른/전문가 검수 후 확정한다.

---

## 1. 먼저 알아둘 것: 책이 두 부분으로 나뉜다

이 책은 페이지 번호가 한 번만 흐르지 않는다. 크게 두 부분이고, 각각 1면부터 다시 시작한다.

| 구분 | 범위 | 내용 |
|---|---|---|
| 전편 | 1~47면 | 서문, 추고, 구보 서문 번역, 목차 |
| 전편 사진·부록 | 49~66면 | 묘소·제각·정려 사진(49~62), 항렬표(63), 조견색인(65~66) |
| 미수록 | 48, 64, 67~93면 | 스캔에 없음. 사이트에서는 “미수록”으로 표시 |
| 본편 | 1~938면 | 세보(1~935), 임원록(936), 수단(937), 간기(938) |

- `전편 1면`과 `본편 1면`은 다른 페이지다. 말할 때는 반드시 `전편/본편`을 붙인다.
- 폴더는 `scan/frontmatter/`(전편)와 `scan/genealogy/`(본편)로 나뉜다.
- `scan/frontmatter/047.jpg`는 전편 47면 목차, `scan/frontmatter/046.jpg`는 전편 46면 서문이다.
- `scan/genealogy/001.jpg`는 본편 1면이다. `scan/genealogy/063.jpg`는 본편 63면의 세보이고, 항렬표는 `scan/frontmatter/063.jpg`(전편 63면)에 있다.
- `上159`는 “본편 159면에 부모(조상)의 기록이 있다”는 뜻이다.
- `下4`는 “본편 4면에 자손의 상세 기록이 이어진다”는 뜻이다. (페이지 하단에 주로 위치하며, `T4`나 `F4`로 오독하기 쉬우니 주의한다.)

## 2. 한 페이지의 기본 구조

세보는 **오른쪽에서 왼쪽으로, 위에서 아래로** 읽는다. 한 페이지는 대개 **한 가문의 가족 단위**다.

1. **오른쪽 위(또는 첫 열)의 인물**이 그 페이지의 기준 인물이다. 보통 이전 페이지 기준 인물의 아들·딸이다. 이름 앞의 `子`는 “아들”이라는 뜻이다.
2. **아래로 내려가며 한 행씩** 그 기준 인물의 자녀를 읽는다. 행의 오른쪽에는 자녀 이름, 왼쪽에는 배우자·자녀(손자)·생몰·묘소 등이 붙는다.
3. 행 아래에 **손자**가 이어지고, 그 옆에 `上###`가 붙으면 그 손자의 상세 기록이 있는 본편 페이지로 이동한다.
4. 페이지 아래쪽의 작은 글씨는 보충 설명(거주지, 묘소, 배우자 집안 등)일 수 있다. 이름과 구분해서 읽는다.

### 본편 25면 예시

- 기준 인물: `子仁居`
- 행: `子時興`, `女崔欽祖`, `女美海擎`, `子榮茂`, `子連泰` ...
- 아래: `子萬元 上159`, `子萬迪 上168`, `子萬純 上170` ...
- 읽기: 仁居의 아들 時興, 딸(사위 崔欽祖), 딸(사위 美海擎), 아들 榮茂, 連泰... 그리고 萬元은 본편 159면에 상세 기록이 있다.

### 본편 217면 예시

- 기준 인물: `子洪東` (字 龍山, 1929년생)
- 행: `女美諧順`, `子洪覺`, `子澈秀 上738`
- 읽기: 洪東의 딸 美諧順, 아들 洪覺, 아들 澈秀. 澈秀의 상세 기록은 본편 738면.

### 본편 1면 예시

- `一世 杜慶寧`, `二世 杜子建`, `三世 杜宣龍` ... `六世`까지 한 표에 정리되어 있다.
- 이 페이지는 예외적으로 **행이 세대**다. 다른 페이지는 행이 자녀다. 이 차이를 꼭 기억한다.

### 본편 63면 예시

- `萬元 上15`가 먼저 나오고, 아래에 `子碩喆`, `子光林`, `子德巖`, `子永眞`, `子洪良`이 이어진다.
- 萬元의 상세 기록은 본편 15면. 아래 `子`들은 같은 가족 단위의 자녀들로 보이나, 기준 인물과의 정확한 관계는 `[확인 필요]`.

## 4. 인물을 추적하는 순서

1. `早見索引`(조견색인)이나 `목차`에서 이름을 찾는다.
2. 해당 본편 페이지로 간다.
3. 오른쪽 위 기준 인물을 확인한다.
4. 행을 따라 자녀·배우자·손자를 읽는다.
5. `上###`가 있으면 그 페이지로 이동해 같은 방식으로 읽는다.
6. 세대는 행 번호로 추정하지 말고, 1면의 1~6세 표, 항렬자, 부모-자녀 연결을 함께 본다.

### 동명이인 구분

같은 이름이 여러 명일 수 있다. 다음을 함께 비교한다.

- 세대(몇 세/몇 대손)
- 파(金浦派 등)
- 배우자와 처가 본관
- 아버지/할아버지
- `上###` 참조 페이지
- 생몰 간지와 묘소

## 5. 항렬자

- `行列名字例`는 전편 63면 `scan/frontmatter/063.jpg`에 있다. 세대별 항렬자 후보를 3개씩 제시하는 표로 보인다.
- 같은 세대의 이름은 항렬자(돌림자)를 공유하는 경우가 많다. 이름에서 항렬자가 앞·가운데·뒤 중 어디에 오는지도 함께 본다.
- 항렬자는 **추정 단서**이지 절대 규칙이 아니다. 이름이 다르거나 다른 파를 쓰는 경우가 있다.
- `scan/genealogy/063.jpg`는 본편 63면 세보이므로 항렬표와 혼동하지 않는다.
- 항렬표의 정확한 세대 범위와 적용 규칙은 `[확인 필요]`.

## 6. 페이지 번호와 파일명

- 전편과 본편은 각각 1면부터 시작한다.
- `scan/frontmatter/001.jpg`~`047.jpg`는 전편 1~47면이다. `047.jpg`가 목차, `046.jpg`가 전편 46면 서문이다.
- `scan/frontmatter/049.jpg`~`063.jpg`는 전편 사진·부록(49~62 사진, 63 항렬표), `065.jpg`~`066.jpg`는 조견색인이다. `048.jpg`와 `064.jpg`는 없다.
- `scan/genealogy/`는 본편이다. 예: `scan/frontmatter/052.jpg`는 전편 52면(묘소 사진)이고, `scan/genealogy/052.jpg`는 본편 52면(세보)이다. 같은 52면이 두 섹션에 있으므로 혼동하지 않는다.
- `scan/frontmatter/063.jpg`는 전편 63면 항렬표, `scan/genealogy/063.jpg`는 본편 63면 세보다.
- 원본 파일명은 3자리 zero-pad(`025.jpg`)이고, 앱이 쓰는 `data/pages/` 경로는 4자리(`0025.jpg`)다.
- 없는 면은 재스캔하지 않고 “미수록”으로 표시한다. 본편 053은 원래 `053.jpg`였던 파일이 52면으로 정정되면서 비게 되었다.

## 7. 용어

| 용어 | 설명 |
|---|---|
| 시조 | 가문의 처음 조상 |
| 중시조 | 중간에 계보를 다시 세운 조상 |
| 입향조 | 특정 지역에 처음 정착한 조상 |
| 세(世) | 시조를 1세로 세는 방식 |
| 대손(代孫) | 시조를 기준으로 몇 대 아래인지. 보통 `n세 = n-1대손` |
| 파(派) | 가문의 분파. 이 책은 金浦派 |
| 항렬자 | 같은 세대 이름에 공통으로 쓰는 글자 |
| 자(字) | 성인 남성이 쓰던 별칭 |
| 호(號) | 문인·학자가 쓰던 별칭 |
| 배(配) | 배우자 |
| 묘소 | 무덤 |
| 좌향 | 무덤의 방향. 예: 艮坐坤向 |
| 상(上) | 해당 인물의 상세 기록이 있는 페이지 참조 |
| 조견색인 | 이름으로 인물을 빨리 찾는 색인 |
| 소목록 | 세대별로 인물을 정리한 목록 |
| 수단 | 발간 비용을 낸 사람 명단 |
| 간기 | 책의 발간·인쇄 정보 |
