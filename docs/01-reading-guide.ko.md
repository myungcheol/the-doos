## 1. 먼저 알아둘 것: 책이 두 부분으로 나뉜다

이 책은 페이지 번호가 한 번만 흐르지 않는다. 크게 두 부분이고, 각각 1면부터 다시 시작한다.

| 구분 | 범위 | 내용 |
|---|---|---|
| 전편 | 1~47면 | 서문, 추고, 구보 서문 번역, 목차 |
| 전편 사진·부록 | 49~66면 | 묘소·제각·정려 사진(49~62), 항렬표(63), 조견색인(65~66) |
| 본편 | 1~938면 | 세보(1~935), 임원록(936), 수단(937), 간기(938) |
| 미수록 | 전편 48·64·67~93면, 본편 53·934·935면 | 스캔에 없음. 사이트에서는 “미수록”으로 표시 |

- `전편 1면`과 `본편 1면`은 다른 페이지다. 말할 때는 반드시 `전편/본편`을 붙인다.
- 폴더는 `scan/frontmatter/`(전편)와 `scan/genealogy/`(본편)로 나뉜다.
- `scan/frontmatter/047.jpg`는 전편 47면 목차, `scan/frontmatter/046.jpg`는 전편 46면 서문이다.
- `scan/genealogy/001.jpg`는 본편 1면이다. `scan/genealogy/063.jpg`는 본편 63면의 세보이고, 항렬표는 `scan/frontmatter/063.jpg`(전편 63면)에 있다.
- `上159`는 “본편 159면에 부모(조상)의 기록이 있다”는 뜻이다. `見上十三`처럼 `見上`이 붙거나 숫자가 한자(十三)인 표기도 있다.
- `下4`는 “본편 4면에 자손의 기록이 이어진다”는 뜻이다. 페이지 하단에 주로 위치하며, 스캔에서 `T4`·`F4`로 보이는 것은 `下4`의 오독이다.

## 2. 한 페이지의 기본 구조

세보는 **위에서 아래로(단 순서), 각 단 안에서는 오른쪽에서 왼쪽으로** 읽는다. 한 페이지는 대개 **한 직계 가문의 여러 세대**를 위에서 아래로 이어 붙인 단위다.

### 단(段)과 세대

- 페이지를 가로로 나눈 줄을 **단(段)** 이라고 한다.
- **원칙적으로 같은 단 = 같은 세대**다. 한 단에는 그 세대의 형제·자매(남계 혈손과 딸)가 실린다.
- 한 단 안에서는 **오른쪽부터 장남, 차남** 순으로 기록된다.
- 딸(`女`) 항목의 위치는 페이지마다 다르다. 아들 항목의 오른쪽에 오는 경우도 있고, 아들 사이에 끼는 경우도 있다. 오른쪽→왼쪽은 **아들 형제의 순서**를 읽는 기본 원칙으로 적용하고, 딸은 `女` 표시로 구분한다.
- **바로 아래 단은 다음 세대**다. 원칙적으로 위 단의 직계 인물과 아래 단의 직계 인물이 부모-자녀 관계다.
- 아래 단의 모든 사람이 위 단의 모든 사람의 자녀는 아니다. `子`로 이어진 직계 자녀가 아래 단으로 이어지고, 나머지는 그 형제·자매다.
- 딸의 자손(외손)은 그 딸 항목 아래에 세로로 이어 적힌다. 앞 페이지의 딸 항목에 붙는 경우도 있고, 단 경계와 무관하게 붙을 수 있으므로 단만 보고 세대를 단정하지 않는다.
- 펼침면(예: 062–063면)에서는 같은 단이 페이지 경계를 넘어 이어질 수 있다. 앞 페이지 안쪽 끝의 딸 항목과 다음 페이지 안쪽 끝의 작은 글씨 자녀가 마주보는 경우가 있다.
- 한 사람의 이름에서 왼쪽으로 `配`(배우자)·`字`·`號`·생몰·묘소·관직 등이 이어 붙는다.
- 페이지 아래쪽의 작은 글씨는 보충 설명(거주지, 묘소, 배우자 집안 등)일 수 있다. 이름과 구분해서 읽는다.

### 페이지의 시작 인물

- 첫 단에서 페이지를 시작하는 인물(보통 `子`가 붙은 사람)이 그 페이지의 **직계 시작 인물**이다(02 문서에서는 **기준 인물**). 같은 단 오른쪽에 딸(`女`) 항목이 올 수 있다.
- `子`는 “아들”이라는 뜻이고, 위 단(또는 앞 페이지)의 직계 인물의 아들이라는 표시다.
- 페이지가 새로 시작하면 `子` 없이 이름만 적고 `上###`로 아버지를 가리키는 경우가 있다. 예: 63면 `萬元 上15`, 217면 `萬宜 上29`.
- 기준 인물 위에 **아버지 이름이 작은 글씨로** 붙는 경우가 있다. 예: 217면 첫 단의 `連泰`. 이때 `上###`는 그 아버지/조상의 기록이 있는 면을 가리킨다.

### 본편 25면 예시

- 이 페이지는 **5개의 단**으로 되어 있다.
- 1단: `子仁居` (맨 오른쪽).
- 2단: `女美海擎`, `女崔欽祖`, `子時興` → 仁居의 자녀 세대.
- 3단: `子榮茂` → 다음 세대.
- 4단: `子連泰` → 다음 세대.
- 5단: `子萬元`, `子萬迪`, `子萬純`, `子萬成`, `子萬益`, `子萬大`, `子萬赫` → 다시 다음 세대. 이름 아래에 `下159`·`下168`·`下170`·`下183`·`下187`·`下188`(스캔에는 `T`/`F`로 보임) 같은 표시가 붙어 자손 기록이 이어지는 면을 가리킨다.
- 따라서 萬元은 仁居의 **손자 세대가 아니라 4단계 아래** 세대다. 한 페이지가 이렇게 여러 세대에 걸칠 수 있다.
- 각 단의 정확한 부자 관계는 `上`/`下` 참조와 가로 위치를 함께 봐야 확정된다. `[확인 필요]`

### 본편 217면 예시

- 페이지 시작 인물(기준 인물): `萬宜`. 
- `萬宜` 위의 작은 글씨 `連泰`는 아버지 이름으로 보이며, `上29`는 그 조상의 기록이 있는 면을 가리킨다.
- 마지막 단의 `澈秀` 아래에는 `下738`(스캔에는 `F738`)이 있어, 738면에 자손 기록이 이어짐을 나타낸다.

### 본편 1면 예시

- 각 단에 `一世 杜慶寧`, `二世 杜子建`, `三世 杜宣龍` … `六世`까지 세대 표기가 붙어 있다.
- **예외 페이지가 아니라, 단 = 세대임을 가장 분명하게 보여주는 기준 페이지**다. 구조를 헷갈릴 때 이 면을 다시 본다.

### 본편 63면 예시

- 이 페이지도 **6개의 단**으로 되어 있다.
- 1단: `萬元 上15` → 萬元의 조상(부모) 기록은 본편 15면에 있다.
- 2단: `女金日長`, `女田權五`, `女姜仁豐`, `子碩喆` → 萬元의 자녀 세대.
- 3단: `女金東赫`, `子光林` → 碩喆의 자녀 세대.
- 4단: `子金容琯`(오른쪽 작은 글씨), `女高錫萬`(가운데), `子德巖`(왼쪽). `德巖`과 `女高錫萬` 항목(딸)은 光林의 자녀 세대다. 다만 오른쪽 작은 글씨 `子金容琯`은 光林의 자녀가 아니라, 앞 페이지 `scan/genealogy/062.jpg` 4단 가장 왼쪽의 딸(`女金仁斗`)의 아들, 즉 光林의 **손자(외손)**다. 작은 글씨는 인쇄된 단과 실제 세대가 다르다는 표시다.
- 5단: `子永眞` → 德巖의 자녀 세대.
- 6단: `子洪良` → 永眞의 자녀 세대.
- 이름이 같아도 세대와 참조가 다르면 동명이인일 수 있다. 25면과 63면의 `萬元`처럼 `上`/`下` 참조가 다르면 세대를 함께 확인한다.

## 4. 인물을 추적하는 순서

1. `早見索引`(조견색인)이나 `목차`에서 이름을 찾는다.
2. 해당 본편 페이지로 간다.
3. 첫 단에서 페이지를 시작하는 인물(**직계 시작 인물**)을 확인한다. `子`가 없으면 `上###`로 아버지를 가리키는 경우이므로, 그 위에 붙은 아버지 이름과 함께 읽는다.
4. 한 단 안에서는 **오른쪽→왼쪽**으로 읽으며, 같은 세대의 형제·자매와 그 왼쪽에 붙은 배우자·생몰·묘소를 확인한다.
5. **바로 아래 단**으로 내려가 다음 세대를 읽는다. 손자로 건너뛰지 않는다.
6. `上###`가 있으면 그 면으로 가서 **조상(부모) 쪽 기록**을 확인한다. `下###`가 있으면 **자손 쪽 기록**을 따라간다.
7. 단은 상대적인 세대 순서만 알려준다. 절대 세대수는 1면의 `一世`~`六世` 표, 항렬자, 부모-자녀 연결을 함께 보고 정한다.

### 동명이인 구분

같은 이름이 여러 명일 수 있다. 다음을 함께 비교한다.

- 세대(몇 세/몇 대손)
- 파(金浦派 등)
- 배우자와 처가 본관
- 아버지/할아버지
- `上###` 참조 페이지
- 생몰 간지와 묘소

## 5. 항렬자

- `行列名字例`는 전편 63면 `scan/frontmatter/063.jpg`에 있다. 세대별 항렬자 후보를 3개씩 제시하는 표로 보인다.
- 같은 세대의 이름은 항렬자(돌림자)를 공유하는 경우가 많다. 이름에서 항렬자가 앞·가운데·뒤 중 어디에 오는지도 함께 본다.
- 항렬자는 **추정 단서**이지 절대 규칙이 아니다. 이름이 다르거나 다른 파를 쓰는 경우가 있다.
- `scan/genealogy/063.jpg`는 본편 63면 세보이므로 항렬표와 혼동하지 않는다.

## 6. 페이지 번호와 파일명

- 전편과 본편은 각각 1면부터 시작한다.
- `scan/frontmatter/001.jpg`~`047.jpg`는 전편 1~47면이다. `047.jpg`가 목차, `046.jpg`가 전편 46면 서문이다.
- `scan/frontmatter/049.jpg`~`063.jpg`는 전편 사진·부록(49~62 사진, 63 항렬표), `065.jpg`~`066.jpg`는 조견색인이다. `048.jpg`와 `064.jpg`는 없다.
- `scan/genealogy/`는 본편이다. 예: `scan/frontmatter/052.jpg`는 전편 52면(묘소 사진)이고, `scan/genealogy/052.jpg`는 본편 52면(세보)이다. 같은 52면이 두 섹션에 있으므로 혼동하지 않는다.
- `scan/frontmatter/063.jpg`는 전편 63면 항렬표, `scan/genealogy/063.jpg`는 본편 63면 세보다.
- 원본 파일명은 3자리 zero-pad(`025.jpg`)이고, 앱이 쓰는 `data/pages/` 경로는 4자리(`0025.jpg`)다.
- 없는 면은 재스캔하지 않고 “미수록”으로 표시한다. 본편 053은 원래 `053.jpg`였던 파일이 52면으로 정정되면서 비게 되었다.

## 7. 용어

| 용어 | 설명 |
|---|---|
| 시조 | 가문의 처음 조상 |
| 중시조 | 중간에 계보를 다시 세운 조상 |
| 입향조 | 특정 지역에 처음 정착한 조상 |
| 세(世) | 시조를 1세로 세는 방식 |
| 단(段) | 페이지를 가로로 나눈 줄. 같은 단이 같은 세대다 |
| 대손(代孫) | 시조를 기준으로 몇 대 아래인지. 보통 `n세 = n-1대손` |
| 파(派) | 가문의 분파. 이 책은 金浦派 |
| 항렬자 | 같은 세대 이름에 공통으로 쓰는 글자 |
| 자(字) | 성인 남성이 쓰던 별칭 |
| 호(號) | 문인·학자가 쓰던 별칭 |
| 배(配) | 배우자 |
| 묘소 | 무덤 |
| 좌향 | 무덤의 방향. 예: 艮坐坤向 |
| 상(上) | 조상(부모) 기록이 있는 면을 가리키는 표시. `見上十三`처럼 쓰기도 한다 |
| 하(下) | 자손 기록이 이어지는 면을 가리키는 표시 |
| 조견색인 | 이름으로 인물을 빨리 찾는 색인 |
| 소목록 | 세대별로 인물을 정리한 목록 |
| 수단 | 발간 비용을 낸 사람 명단 |
| 간기 | 책의 발간·인쇄 정보 |
